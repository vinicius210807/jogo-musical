# 🎸 Jogo Musical

Projeto acadêmico de desenvolvimento de um jogo 2D de ritmo e gerenciamento de carreira musical, inspirado em jogos musicais clássicos.

O jogador começa sua carreira como músico independente e precisa evoluir suas habilidades, ganhar dinheiro e conquistar fama para construir sua própria banda.

## 🎮 Sobre o jogo

O jogador poderá escolher sua carreira musical, começando como cantor, guitarrista, baterista ou baixista.

Por meio de desafios musicais baseados em ritmo, será possível acumular dinheiro e fama, adquirir equipamentos, contratar novos integrantes e evoluir de uma simples garagem para um ambiente musical profissional.

## ✨ Funcionalidades planejadas

- Escolha de carreira musical.
- Sistema de jogo rítmico com notas musicais.
- Pontuação, combos e avaliação de desempenho.
- Sistema de dinheiro e fama.
- Contratação de integrantes para formar uma banda.
- Compra e melhoria de equipamentos.
- Evolução dos ambientes conforme o progresso.

## 🛠️ Tecnologias

- CSS3
- JavaScript
